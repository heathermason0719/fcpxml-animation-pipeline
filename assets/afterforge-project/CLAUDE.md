# AfterForge

先遵循同目录 `AGENTS.md`。这是电影系列的动画工作区：围绕当前作品与反馈工作，用 `fcpxml-animation-pipeline` 的统一 CLI，保留原素材、精确时间、制作版 runtime 和不可变交付。

默认读取 `工程/创作记忆.md` 的简明共识及选中版本的视觉规范；不加载全部历史阶段文档。旧 schema 2.0 只读，继续制作显式创建新副本。

首次设计、反馈 handoff、完整审阅与交付分别记录；首次确认后的对象可以直接按明确目标修改和局部试做，不回退首次入口。完整 Demo 必须有当前 taskId、工作与展示范围的明确授权；探索候选未采用前不改变制作源。

静态 layout 只承载受限声明式内容，静态 host 不加载用户脚本或 vendor JS；可执行/时间驱动来源及其依赖绑定变更必须通过完整依赖闭包的 production check。runtime 配置只由 runtime 操作维护。跨版本继续需要 commission 和明确的 restart 或 Cue 级 new/continue continuity；继续只带 qualification provenance，不带审阅或授权。缺失展示目标默认拒绝；allowDraft 是未完成讨论，明确 exclusion 不能成为正式 full Review。
