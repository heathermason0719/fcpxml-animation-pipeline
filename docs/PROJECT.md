# 项目定义

## 项目是什么

`fcpxml-animation-pipeline` 是一个可复用的 Codex Skill 项目，用于把 Final Cut Pro 粗剪时间线、旁白、字幕和简要动画要求组织成可执行的动画生产与时间线回填流程。

## 使用者与用途

项目主要服务于使用 Final Cut Pro 制作横屏自媒体视频的创作者。使用者提供实际项目工作区，系统优先从中发现粗剪时间线、低码参考视频、旁白材料和已有设计提示，再负责分析和对齐信息、细化动画方案、协调动画渲染，并生成可重新导入 Final Cut Pro 的交付物。

## 核心目标

- 解析 FCPXML 或 FCPXMLD，可靠识别项目规格、素材引用和时间线结构；
- 将旁白、字幕、动画时间点和自然语言要求对齐为结构化动画清单；
- 在保留创作判断空间的同时，把时间计算、素材注册和 XML 回填交给确定性脚本；
- 使用 HyperFrames 作为首个动画渲染后端，同时保持分析与回填流程不依赖单一渲染工具；
- 生成新的 FCPXML 及其引用的动画素材，使用户可以导入 Final Cut Pro 继续编辑；
- 全程保留原始工程和输入素材，提供可验证、可追踪、可重复执行的结果。

## 当前范围

- 项目以用户提供的实际工作区为入口，不要求用户逐个搬运工作区中已经存在的材料；
- Skill 接入后在项目根目录创建或识别独立用户工作目录；当前默认显示名是 `AfterForge`，该名称可替换且不属于内部协议或身份；
- 每个 AfterForge 视频项目只在首次项目初始化时于工作目录根层创建一次项目级 `AGENTS.md` 和 `CLAUDE.md`；创建后不因新增 Vn、HyperFrames 升级或普通制作自动覆盖或刷新；
- `AfterForge/frame.md` 是该视频项目视觉包装规范的 canonical source；每个 Vn HyperFrames 工程保存本版构建时快照及其校验信息，确保旧版本可以独立重渲染；
- 项目根目录包含由用户维护、Skill 只读的 `user-inbox/`；用户自行创建和选择扁平的 `YYYY-MM-DD_Vn/` 或 `YYYY-MM-DD_vn/` 投放版本目录，Skill 原样保留选定拼写并阻止仅大小写不同的版本碰撞；
- 必要输入是粗剪 FCPXML/FCPXMLD 和对应的低码粗剪参考视频；
- 旁白 SRT、时间线字幕、纯转写稿或已有文字稿是可替代的旁白证据来源，已有一种足够时不重复索取其他形式；
- Marker、时间线设计文字、notes 或其他主观设计材料存在时作为约束；动画要求和 animation brief 默认不是必要输入；
- Skill 内置一份可按需提供的动画脚本回填模板，帮助用户规范表达可选要求；模板不自动写入项目、不替代自由格式脚本，也不成为 intake 必填项；
- 首要使用场景是 16:9 横屏口播类视频；
- 动画设计包含文字、图形、遮罩、示意演示和转场提示；声音制作不属于 AfterForge 工作流；
- 每个视频项目在正式动画实施前单独确认并冻结整体视觉包装规范与统一运动气质；视觉规范覆盖构图、层级、图形语言、材质、影像处理、色彩、字体和组件等整体审美，不只是颜色与字体；
- 动画文字方案和使用真实文案的静态关键画面由系统内部依次准备，并在 cue / still 就地 comment 的 Storyboard 页面合并为静态样式验收；每个 animated cue 以一个简洁自然语言 `finalAnimationDescription` 表达进入 A11 时的最终呈现，不展示讨论历史；每镜必须有 1 张主审帧，存在额外静态构图状态时可再附 1–2 张辅助帧；
- Storyboard 静态审核通过后才生成 854×480 全运动 Demo；Demo comment 自动关联播放器时间和当前 cue，可选持续范围，并允许用户在一条完整意见上选择 static、motion 或二者影响范围；
- 静态样式和 480p 运动审核全部通过后，仍需用户针对当前获批输入单独授权，才可开始原生透明通道视频渲染；
- 动画渲染初期采用 HyperFrames，最终动画素材以适合 Final Cut Pro 合成和继续编辑的格式交付；
- 输出包括新 FCPXML、关联素材、结构化动画清单和必要的人工确认项。

## 明确不做

- 不替代 Final Cut Pro 完成全部剪辑、调色和混音；
- 不生成、设计、混合或回填音效与音乐；审阅视频只保留粗剪参考视频自带的原声；
- 不直接覆盖原始时间线、媒体或 Final Cut Pro 资源库；
- 不承诺在缺少字幕时间、旁白对齐依据或足够上下文时猜测精确动画位置；
- 不把可从工作区、FCPXML、参考视频或现有文字自行取得的事实信息再次列为用户必填项；但多段原片需在动画内重新编排时，用户对精确取段和顺序的创作选择不属于可自行推断的信息；
- 不把受版权保护的电影原片或用户媒体纳入仓库版本控制；
- 不在当前阶段建设与核心工作流无关的通用视频编辑平台。
- 不自动创建、递增、移动、重命名或删除 `user-inbox/` 中的版本和材料。

## 重要约束

- FCPXML 时间计算必须尊重源项目帧率和有理数时间表示；
- 所有回填素材必须具有稳定、可迁移且可校验的引用关系；
- 创作性判断与机械性 XML 操作应通过明确的中间数据格式解耦；
- 具体动画设计必须先判断信息功能及其与原电影画面的关系，再选择可参考的视觉语言；该判断由 Agent 默认自主完成，并在既有 storyboard 验收中暴露，不增加逐条确认负担。初始设计及后续 Review / 聊天反馈修改中，若用户措辞和已确认约束仍支持两种以上会实质改变最终构图、必要内容、运动方式或特殊约束的合理解释，必须在修改受影响 cue 前提出一个聚焦问题；已有批准、赶时间、低成本返工或后续可 comment 都不能代替澄清。明确结果内的技术实现细节仍由 Agent 自主完成，澄清不新增批准门；
- 项目级 `frame.md` 和视频级运动气质是默认风格；用户动画脚本对单条镜头明确指定的视觉或运动风格，在该镜及其明确属性范围内具有更高权威，未指定部分继续继承项目默认，且不得覆盖时间、范围、读写、交付或后端能力边界；
- 新制作的运动默认服务于可读性、叙事节奏和后续剪辑：缓入缓停应可感知，按镜头内容与画面比例安排路径、时长和余量，不固定秒数或退场比例；允许有明确用途的持续运动，不以“不漂浮”一概禁止。默认调整不得自动改写已交付 Vn，也不构成子区间摆放或源时间线修改授权；
- 动画需在内部重放、重排、裁切、遮罩或多画面合成两段或以上原片时，默认以用户提供的独立、带余量片段为创作选择权威；只有用户明确给出精确源范围并授权代为提取时才可例外；
- 素材身份与选择以用户最新明确说明及实际投放文件的名称、编号顺序和可检查内容为权威；脚本中列出的素材类型只作规划参考，除非用户再次明确确认其为硬要求；
- A8 与 A11 以尽快交付用户验收为优先；低成本自动检查只作非阻塞自检，只有 storyboard 无法打开、关键资源缺失或页面明显报错等导致用户无法查看结果的问题才阻塞，Agent 不代替用户完成审美验收；
- A11 已批准 hero frame 与 A12 正式动画必须共享同一 cue composition 布局源；storyboard 只生成 review projection，运动独立保存且不得重新定义已通过的布局；
- Storyboard 与 480p Demo 的 comment、解决状态和批准结果必须形成当前 Vn 内可校验的结构化记录；Storyboard 绑定 cue / still，并在同一上下文展示 manifest 中已对齐的设计描述与确认补充，Demo 自动绑定播放器时间、当前 cue 与可选时间段，不能只保留在聊天或浏览器临时状态中，也不能要求用户重复选择机器已知的上下文；
- 原生透明动画渲染必须 fail closed：Storyboard 静态审核、480p Demo 运动审核、有效 layout lock 和针对当前输入的用户显式授权缺一不可，且任何相关输入变化都使下游批准或授权失效；
- A-stage 与 D-stage 的身份和职责由版本化 Stage Contract 统一定义；单个 Vn 只保存合同版本和实例 evidence，当前进度由 evidence 推导，不人工同步 `currentStage`；
- 自动化无法可靠决定的内容必须显式列为人工确认项；
- 任何渲染后端的替换都不应迫使时间线分析和 FCPXML 回填逻辑整体重写。
- 用户侧工作目录显示名不得驱动仓库名、Skill ID、数据字段或内部索引迁移。
- `AfterForge/` 是 Skill 唯一默认写入区；`user-inbox/` 及版本内容始终视为用户只读输入。
- AfterForge 项目初始化与 Vn 版本创建必须解耦；创建 Vn 不得重新生成或自动更新项目级 `AGENTS.md`、`CLAUDE.md` 或 canonical `frame.md`。
- 新 Vn 只在创建时确定并精确固定 HyperFrames runtime；已进入制作的 Vn 不随官方 latest 自动漂移，版本变化必须是用户授权、可观察且能传播审核 evidence 失效的显式迁移。

## 主要目标成立的条件

当一组受支持的项目输入能够被稳定解析、形成可审阅的动画清单、生成动画素材、回填为不破坏原粗剪的新 FCPXML，并通过自动检查及 Final Cut Pro 实际导入验证时，项目的主要目标成立。
